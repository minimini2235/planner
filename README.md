# 흑백 플래너

연 · 월 · 주 플래너와 할일 로드맵. 폰과 컴퓨터에 설치해서 쓰는 웹앱(PWA)입니다.

## 폴더

| 폴더 | 내용 | GitHub에 올라가나 |
|---|---|---|
| `app/` | 앱 본체. 수정은 `app/index.html`에서 | 올라감 (공개) |
| `기획/` | 디자인 PDF, 기능 설명 | 안 올라감 |
| `이전버전/` | 첫 데모, 아티팩트 데모 | 안 올라감 |
| `.github/workflows/` | `app/`이 바뀌면 자동으로 배포 | 올라감 |

## 업데이트하는 법

1. `app/index.html`을 고칩니다.
2. GitHub에 올리면 1~2분 뒤 자동으로 배포됩니다.
3. 앱을 열면 새 버전이 적용됩니다. `app/sw.js`를 바꿨다면 "새 버전이 준비됐어요 · 새로고침" 알림이 뜹니다.

`sw.js`나 그 안의 파일 목록을 바꿀 때는 맨 위 `VERSION` 값을 올립니다 (`v1` → `v2`).

## 데이터를 지키는 규칙

- 데이터는 앱 파일과 따로, 각 기기의 브라우저 저장소에 있습니다. 앱을 업데이트해도 지워지지 않습니다.
- 저장 이름 `bw-planner-demo-v1`은 바꾸지 않습니다. 바꾸면 저장된 데이터를 못 찾습니다.
- 데이터 모양을 바꿀 때는 `SCHEMA`를 1 올리고, `MIGRATIONS`에 예전 모양을 새 모양으로 고치는 코드를 넣습니다. 지우지 않고 고칩니다.
- 앱은 하루 한 번, 그리고 데이터 모양이 바뀌기 직전에 사본(`…-backup`)을 따로 저장합니다.
- 다른 기기나 새 주소로 옮길 때: 설정 → 데이터 → 백업 복사 / 붙여넣기.
